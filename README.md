# Монте Карло симулација VFR–IFR прелаза на аеродрому LYBT

Овај репозиторијум садржи дискретну стохастичку симулацију повратка и слетања ваздухоплова на аеродром **Београд/Батајница (LYBT)** након промене метеоролошких услова из VFR у IFR.

Пројекат је развијен за потребе предмета **Симулационо моделирање на докторским академским студијама**. Основни циљ је испитивање утицаја тренутка погоршања метеоролошких услова на оптерећење прилазног тока, задржавање ваздухоплова, потрошњу горива и исход планираних летова.

> Модел је истраживачки и образовни. Није намењен оперативном планирању летења нити доношењу одлука у стварном ваздушном саобраћају.

## Истраживачки експеримент

Главни експеримент пореди пет тренутака преласка са VFR на IFR услове:

- 30. минут;
- 45. минут;
- 60. минут;
- 75. минут;
- 90. минут.

За сваки тренутак изводи се **1.000 Монте Карло репликација**, односно укупно 5.000 симулационих покретања. У свим сценаријима за исту репликацију користи се исти случајни seed (*common random numbers*), како би поређење тренутака преласка било мање оптерећено случајним варијацијама.

Подразумеване вредности у `run_sim.py` су:

```python
TRANSITION_MINUTES = (30, 45, 60, 75, 90)
N_REPLICATIONS = 1000
BASE_SEED = 20_260_707
```

## Шта модел обухвата

Симулација обухвата:

- заједнички план летења са више летова истог физичког ваздухоплова;
- активности `AERIAL_WORK`, `EN_ROUTE` и `AERODROME_CIRCUIT`;
- стохастичко одступање времена полетања и трајања појединих фаза лета;
- прекид VFR активности након наступања IFR услова и повратак ваздухоплова према аеродрому;
- визуелне и инструменталне прилазе;
- редослед прилаза према приоритету, категорији ваздухоплова и стању горива;
- временско и просторнo раздвајање, категорије турбулентног трага и заједничку путању од тачке LANEN;
- Blumstein-ов модел потребног временског размака, допуњен Harris-овим бафером за грешку испоруке ваздухоплова;
- заузетост полетно-слетне стазе и време њеног ослобађања;
- holding и потрошњу горива по фазама лета;
- статусе горива `NORMAL`, `LOW_FUEL` и `EMERGENCY`;
- могућност неуспелог прилаза (`go-around`), поновног доласка од MAPt до IAF и поновљених покушаја прилаза;
- слетање, одлазак на алтернативни аеродром, отказивање лета и останак без горива;
- опциони сценарио привременог затварања ПСС 12L/30R и употребу алтернативне ПСС 12R/30L ваздухопловима са одговарајућом RNP способношћу.

У плану и бази перформанси заступљени су типови **MiG-29, G-4, H145, Mi-17, CASA, An-26 и Lasta**.

## Предуслови и инсталација

Потребан је Python 3.10 или новији. Препоручује се употреба виртуелног окружења.

### Windows PowerShell

```powershell
git clone https://github.com/IvanSibinovic/lybt_sim.git
cd lybt_sim

py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Ако PowerShell не дозвољава активирање окружења, исте команде се могу извршити у Command Prompt-у:

```cmd
.venv\Scripts\activate.bat
```

### Linux и macOS

```bash
git clone https://github.com/IvanSibinovic/lybt_sim.git
cd lybt_sim

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Главне зависности су NumPy, pandas и Matplotlib.

## Покретање симулације

Из кореног директоријума репозиторијума покренути:

```bash
python run_sim.py
```

Покретање подразумеваног експеримента може потрајати јер се извршава 5.000 симулација. За брзу проверу исправности може се привремено смањити `N_REPLICATIONS` у `run_sim.py`, на пример на 10 или 50. За коначни експеримент вредност треба вратити на 1.000.

Основна синтаксна провера Python датотека може се извршити командом:

```bash
python -m compileall run_sim.py src
```

## Подешавање сценарија

Главни параметри налазе се у `src/lybt_sim/config.py` и `run_sim.py`.

| Параметар | Значење |
|---|---|
| `SIM_DURATION_SEC` | Основно планирано трајање симулације. |
| `DT_SEC` | Дужина дискретног временског корака. |
| `TAKEOFF_JITTER_MIN` | Интензитет стохастичког одступања времена полетања. |
| `TAKEOFF_JITTER_LIMIT_MIN` | Највеће дозвољено одступање од номиналног времена полетања. |
| `LOW_FUEL_ENDURANCE_MIN` | Праг преостале издржљивости за статус `LOW_FUEL`. |
| `EMERGENCY_ENDURANCE_MIN` | Праг преостале издржљивости за статус `EMERGENCY`. |
| `ENABLE_RUNWAY_12L_CLOSURE` | Укључује или искључује привремено затварање ПСС 12L/30R. |
| `RUNWAY_12L_CLOSURE_DELAY_SEC` | Одлагање почетка затварања у односу на наступање IFR услова. |
| `RUNWAY_12L_CLOSURE_DURATION_SEC` | Трајање затварања ПСС. |
| `TRANSITION_MINUTES` | Тренуци VFR→IFR прелаза који се пореде. |
| `N_REPLICATIONS` | Број репликација за сваки тренутак прелаза. |
| `BASE_SEED` | Основа за репродуктивно генерисање случајних бројева. |

За основни сценарио без затварања стазе поставити:

```python
ENABLE_RUNWAY_12L_CLOSURE = False
```

За сценарио са привременим затварањем поставити:

```python
ENABLE_RUNWAY_12L_CLOSURE = True
```

## Улазни подаци

Улазни подаци смештени су у директоријум `data/`:

- `common_fpl.json` дефинише тип и ID физичког ваздухоплова, редни број лета, планирано време полетања, врсту и трајање активности, време миграције, време повратка и податак о допуни горива;
- `aircraft_performance.json` садржи категорију, брзине, време заузетости стазе, количине и потрошњу горива, резерву, време припреме, вероватноћу go-around догађаја и време MAPt–IAF;
- `aip_procedures.json` садржи податке о процедурама прилаза, основним и wake separation минимумима и параметрима Harris-овог бафера;
- `aerodrome_layout.json` описује физичке ПСС и расположиве дужине;
- `star_procedures.json` садржи долазне руте и holding процедуре;
- `simulation_scenarios.json` дефинише основне VFR и IFR сценарије.

## Излазни резултати

Резултати се уписују у директоријум `results/` као CSV датотеке са знаком `;` као раздвајачем, децималним зарезом и UTF-8 кодирањем погодним за отварање у Excel-у.

Када је затварање ПСС искључено, суфикс је `baseline`:

- `experiment_replications_baseline.csv`;
- `experiment_summary_baseline.csv`;
- `aircraft_type_replications_baseline.csv`;
- `aircraft_type_summary_baseline.csv`.

Када је затварање ПСС укључено, суфикс је `rwy_closure`:

- `experiment_replications_rwy_closure.csv`;
- `experiment_summary_rwy_closure.csv`;
- `aircraft_type_replications_rwy_closure.csv`;
- `aircraft_type_summary_rwy_closure.csv`.

Датотеке са ознаком `replications` садрже резултате сваке појединачне репликације, док датотеке са ознаком `summary` садрже агрегиране показатеље по тренутку VFR→IFR прелаза. Датотеке са префиксом `aircraft_type` дају исте врсте показатеља разврстане по типу ваздухоплова.

Међу показатељима се налазе:

- број активних, слетелих, преусмерених, отказаних и незавршених летова;
- вероватноће достизања `LOW_FUEL`, `EMERGENCY` и типске резерве;
- минимална маргина горива и преостала издржљивост;
- просечно и максимално време у holding-у;
- потрошња горива у holding-у;
- број и стопа go-around догађаја;
- број слетања са приоритетом због стања горива;
- исходи по типу ваздухоплова.

## Репродуктивност

За репликацију са редним бројем `r` користи се:

```python
seed = BASE_SEED + r
```

Исти seed примењује се за свих пет тренутака прелаза у тој репликацији. Ако улазни подаци, конфигурација, верзије библиотека и seed остану непромењени, експеримент се може поновити са истим низом случајних реализација.

## Претпоставке и ограничења

- Модел представља поједностављену слику сложеног система ваздушног саобраћаја.
- Део података о перформансама и потрошњи горива заснован је на јавно доступним подацима и истраживачким проценама.
- Вероватноће go-around догађаја и поједина стохастичка одступања представљају параметре модела, а не оперативне прогнозе.
- Секвенцирање прилаза и употреба ПСС моделовани су у складу са циљем експеримента и не обухватају све поступке контроле летења.
- Резултате треба тумачити упоредно, у оквиру дефинисаних сценарија и претпоставки.
